# Network_Information_Security_coursework
The coursework for the subject Network Information Security that I attend at TUES.

Here are the details of the fictional company I would work for and secure its operations:

## PharmaDist OOD

**It distributes medicines to pharmacies nationwide. The central warehouse is located in Sofia,
while regional warehouses are in Shumen and Montana. The ordering system (ERP) is accessible to
everyone. The temperature control system (HVAC) is strictly isolated. Only
specialized technical laptops can communicate with the HVAC system.**
